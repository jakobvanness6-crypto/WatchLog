# Watchlog v3.11.0 - Shift count: what to try on the work PC

Install v3.11.0 the same way as before. v3.10.0 and v3.10.1 items (home window, icons, tabbed Settings, SDS sign-back-in) are still untested on a bay, see the v3.10.1 checklist.

## Shift count
- [ ] Tray > **Shift count** opens a window (also a **Shift count** tile on the home window, and a button in Time saved). Before you do anything it says nothing counted yet.
- [ ] Do a few things: a template (for example ;audit), a time stamp (;t), a login, Ctrl+Alt+A on the Alert Grid, an app switch (Ctrl+Alt+T). Open Shift count again. Each shows as its own line with how many times and keystrokes saved, most used first, and a total at the bottom.
- [ ] **Copy report**, paste into Notepad: numbers and item names only, no log text.
- [ ] **Start a new count** asks first, then the list goes back to empty. The Time saved totals are not touched.
- [ ] After End of shift, the next thing you do starts a fresh count.
- [ ] Count one real shift, then compare the Alert Grid clear and template numbers with what you remember doing.
