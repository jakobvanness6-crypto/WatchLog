# Screenshots for the illustrated overview

Each screenshot goes next to the part of the overview it explains. Take them on your PC with **Win+Shift+S** (Window mode snips just one window). Save them with the number at the start of the name, like `04 audit form.png`, so I know where each one goes.

**Before you send any:** crop out or cover real names, employee numbers, player numbers and anything about patrons. Use made-up details in the forms (like Dealer #123456). Don't capture a screen showing a password, either typed or saved.
